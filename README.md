# ელექტრო მონოციკლი და საქართველოს კანონი

ერთგვერდიანი სტატიკური საცნობარო გვერდი იმის შესახებ, რას ამბობს საქართველოს კანონმდებლობა ელექტრო მონოციკლით (EUC) საზოგადოებრივ გზაზე გადაადგილებაზე. თითოეული დებულება მითითებულია მუხლის ნომრით და კანონის სიტყვასიტყვითი ციტატით, ბმულებით matsne.gov.ge-ზე.

გვერდი: https://euc-georgia.github.io/euc-law-georgia/

არ არის იურიდიული კონსულტაცია.

ბოლო შემოწმება: 6 სექტემბერი 2026.
